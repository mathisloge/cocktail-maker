Which blocks make up the machine, and how do they work with the people and inputs around it?

* **Station:** Handles all high-level logic and the interactions with Guests and Operators.
Both the Guest UI and the Operator UI are hosted here.
The xref:station::building-blocks.adoc[Station building block view] shows its inner blocks.
* **Pod(s):** Handle the low-level, real-time hardware execution.
A Pod receives a command, executes it autonomously by driving its actuators, and reports back.
Operators interact physically with Pods for maintenance.
The xref:mechanics::building-blocks.adoc[Mechanics building block view] describes the mechanical parts of a Pod.
* **Power Management Unit:** The internal bridge between the external power grid and the low-voltage electronics.
* **Show front:** The part of the Station that shows each pour to the Guests with bubbles and light (xref:adr:016-station-show-front.adoc[SYS-016]).
The Station software computes every effect, and the mechanical design builds the hardware.
Their boundary is the contract xref:contracts.adoc#IF-09[IF-09].

The split of the Station and Pod's is decided in xref:adr:001-system-split.adoc[]

The xref:contracts.adoc[Contracts page] states what crosses each boundary between these blocks.
