The xref:context-and-scope.adoc[system context] shows the Cocktail Machine as one black box.
Zooming into the machine, the system is partitioned into three functional domains.

Which blocks make up the machine, and how do they work with the people and inputs around it?

* **Station:** Handles all high-level logic and user interactions.
Both the Guest UI and the Operator Maintenance UI are hosted here.
The xref:station::building-blocks.adoc[Station building block view] shows its inner blocks.
* **Pod(s):** Handle the low-level, real-time hardware execution.
A Pod receives a command, executes it autonomously by driving its actuators, and reports back.
Operators interact physically with Pods for maintenance.
The xref:mechanics::index.adoc[Mechanics docs] describe the mechanical parts of a Pod.
* **Power Management Unit:** The internal bridge between the external power grid and the low-voltage electronics.
