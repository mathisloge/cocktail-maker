Who and what does the machine interact with?

* **Guest:** Interacts with the system purely to order and receive drinks.
Requires zero technical knowledge.
* **Operator:** Responsible for refilling ingredients, executing cleaning cycles, and calibrating Pods.
Interacts with a dedicated Operator UI.
* **Power & Ingredients:** The physical inputs required for operation.
