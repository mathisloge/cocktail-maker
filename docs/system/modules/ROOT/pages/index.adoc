= 1 Introduction and Goals

This document describes the system architecture and design principles of the cocktail-maker.
The system is a fully automated, mechatronic beverage dispenser designed to mix cocktails from various raw ingredients (spirits, juices, syrups) precisely and reliably based on predefined recipes.

A defining characteristic of this project is its highly modular architecture.
Instead of a monolithic design, the system is strictly divided into a central orchestration unit and autonomous Pods.
This approach abstracts the complexity of fluid management and hardware control from the user interface, resulting in a highly scalable and maintainable system.

This documentation serves as the central reference point for hardware design, software development, protocol definition, and future maintenance.
The xref:diagram-conventions.adoc[diagram conventions] explain the shapes, colours and line styles of every diagram.

The following chapters provide a high-level overview of the cocktail-maker.
They define the system boundaries, illustrate the core functional blocks, and document the fundamental architectural decisions that shaped the design before diving into specific hardware or software implementations.

== Requirements Overview

The machine mixes a cocktail from raw ingredients by a recipe and pours it into a glass.
These are its main functions.

* Let a Guest order a drink and receive it in a glass: xref:runtime-view.adoc#drink-end-to-end[A Drink End to End].
* Scale a recipe to the chosen glass and carry it out by commanding the Pods: xref:station::runtime-view.adoc#_a_guest_mixes_a_drink[Station runtime view, A Guest Mixes a Drink].
* Let a Guest cancel a running drink and stop every pump and valve: xref:fault-scenarios.adoc#guest-cancels[A Guest Cancels].
* Find the Pods at the start and tell them apart: xref:runtime-view.adoc#switching-on[Switching On].
* Suspect an empty bottle during a pour and let an Operator refill it: xref:fault-scenarios.adoc#bottle-empty-during-pour[A Bottle Runs Empty During a Pour].
* Let an Operator refill or replace a bottle and keep the fill level of each bottle: xref:runtime-view.adoc#refilling[Refilling].
* Let an Operator calibrate a dispenser: xref:station::runtime-view.adoc#_an_operator_calibrates_a_dispenser[Station runtime view, An Operator Calibrates a Dispenser].
* Let an Operator clean the machine in cleaning cycles.
The xref:context-and-scope.adoc[context] names them, and they are not designed yet (open, xref:contracts.adoc#IF-06-R04[IF-06-R04]).
* Start again with its data intact after the power was cut: xref:fault-scenarios.adoc#power-fails-during-pour[The Power Fails During a Pour].
* Switch off at one labeled main switch: xref:runtime-view.adoc#switching-off[Switching Off].
