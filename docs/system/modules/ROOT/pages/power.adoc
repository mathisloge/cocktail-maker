How does the mains energy reach the actuators and the Raspberry Pi?

The main switch provides a single, clearly labeled point at which an operator can fully disconnect the machine from mains power.
The RCD/circuit breaker protects against both residual current faults and overcurrent conditions before any DC conversion takes place.
A continuous protective earth (PE) conductor is maintained across all stages, from the inlet through to the Station and every Pod.
The detailed rationale for this power architecture is documented in xref:adr:004-power-architecture.adoc[SYS-004].
